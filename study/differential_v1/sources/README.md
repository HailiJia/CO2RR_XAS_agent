# Supplied scientific sources

These independent tar.gz parts preserve logical folders and exact source bytes. Every member and archive hash was verified after compression. No licensed potentials, executable binaries or wavefunction checkpoints are included. `checkpoints.tar.gz` contains time-stamped UNFINISHED OCCO–water snapshots and available trajectories, not converged intermediates or training spectra. The benchmark part includes actual current SCF/XAS OUTCAR/XML/HDF5 files even when the run is incomplete. CuAu/Cu100 parts contain actual per-absorber spectra, canonical convolved curves, absorber tables, input decks and final convolution logs; nonunit-multiplicity cases also preserve BAV evidence. Original record bytes are sources, not silently replaced corrected records.
